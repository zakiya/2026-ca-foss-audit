Overview

Audit of California government web hostnames. Data was collected by from Google Analytics and crawling each hostname. The 155 sites with the highest traffic were scanned.

Key findings

Of the 83 scanned sites with an identifiable platform, 56 run open-source platforms (67%) and 27 run proprietary platforms (33%).

Details

Methodology

Site lists were drawn from a Google Analytics report filtered to the statewide CA.gov tag over a 28-day window (July 1–28, 2026). The original list had 1,227 hostname records. The dataset was then deduplicated and numeric-only entries were removed eaving 1,115 hostnames. The numeric-only entries were likely IP addresses rather than named web properties.

The scanner ran on the top 155 sites by traffic volume. For each of those hostnames, a Python script crawled the site and inspected HTTP response headers and HTML source to identify the underlying platform and classify it as open source or proprietary. Only sites returning HTTP 200 could be fingerprinted. Blocked (403), redirecting, or unreachable sites were marked accordingly. The remaining 959 hostnames were not scanned and have no platform classification.

Because coverage depends on adoption of the statewide GA tag, sites that do not use it are not represented in this dataset.

CSV column descriptions

Download (audit.csv)

hostname-cleaned

The normalized domain or subdomain of a California government web site (e.g., edd.ca.gov, dmv.ca.gov).

canonical-to-text

The canonical URL the hostname resolves to, expressed as plain text.

ga-total-views

Total Google Analytics page views recorded for the hostname across the measurement period. Used as a proxy for public-facing traffic volume. Higher-traffic sites represent broader public impact.

techstack-status

The HTTP status code returned when the hostname was crawled. A blank value means the scanner was not run on this hostname

Only sites returning 200 could have their platform identified.

techstack-opensource-platform

Whether the detected platform is open source. Values:

  • yes — confirmed open-source platform
  • no — confirmed proprietary platform
  • unknown — site was reachable but platform could not be identified
  • error — site was unreachable during scanning
  • blank — not scanned

techstack-platform

The specific CMS or web platform detected. Sites that returned a non-200 status or where detection was inconclusive are marked undetermined.

techstack-frameworks

Third-party JavaScript libraries and tools detected on the page. Blank where none were detected or the site was not scanned.

Notes

  • Hostnames include staging, test, and internal environments in addition to public production sites; traffic figures help distinguish between them.
  • Only the top 155 hostnames by traffic were scanned; findings should not be generalized to all 1,115 hostnames in the dataset.
  • Findings should be interpreted at the hostname level, not the agency level — a single agency may operate multiple hostnames on different platforms.
