2026 California Web Technology Audit

July 2026

Overview

This audit surveyed 1,115 California government web hostnames to assess platform adoption across state agencies. Data was collected by crawling each hostname, detecting its technology stack, and cross-referencing Google Analytics traffic figures.

Methodology

Site lists were drawn from a Google Analytics report filtered to the statewide CA.gov tag over a 28-day window (July 1–28, 2026), yielding 1,227 hostname records. The dataset was then deduplicated and numeric-only entries — likely IP addresses rather than named web properties — were removed, leaving 1,115 hostnames.

The scanner was run only on the top 155 sites by traffic volume. For each of those hostnames, a Python script (to be published on GitHub) crawled the site and inspected HTTP response headers and HTML source to identify the underlying platform and classify it as open source or proprietary. Only sites returning HTTP 200 could be fingerprinted; sites blocked (403), redirecting, or unreachable were marked accordingly. The remaining 959 hostnames were not scanned and have no platform classification.

Because coverage depends on adoption of the statewide GA tag, sites that do not use it — including some agency microsites and third-party-hosted portals — are not represented in this dataset.

Open source Proprietary

Of the 83 scanned sites with an identifiable platform, 56 run open-source platforms (67%) — predominantly WordPress — and 27 run proprietary platforms (33%) — predominantly ASP.NET.

Traffic is skewed toward proprietary platforms. The highest-traffic sites — ca.gov (130M views) and edd.ca.gov (43M views) — both run ASP.NET. Across all identifiable sites, proprietary platforms account for roughly 195 million views compared to 16 million for open-source platforms. This gap reflects that the state's highest-volume transactional sites have not yet migrated to open-source alternatives.

WordPress is the dominant open-source platform, used across 51 agencies ranging from small boards (e.g., bbs.ca.gov) to high-profile sites (e.g., gov.ca.gov, cannabis.ca.gov). Joomla and Drupal have limited but active adoption.

Dataset: Column Descriptions

hostname-cleaned

The normalized domain or subdomain of a California government web property (e.g., edd.ca.gov, dmv.ca.gov). Includes production sites, staging environments, internal tools, and non-.ca.gov domains associated with state agencies.

canonical-to-text

The canonical URL the hostname resolves to, expressed as plain text. In most cases this matches hostname-cleaned; differences indicate redirects or aliasing.

ga-total-views

Total Google Analytics page views recorded for the hostname across the measurement period. Used as a proxy for public-facing traffic volume. Higher-traffic sites represent broader public impact.

techstack-status

The HTTP status code returned when the hostname was crawled. A blank value means the scanner was not run on this hostname — only the top 155 sites by traffic were scanned. Common values for scanned sites:

  • 200 — site responded normally and was scanned
  • 403 — access was blocked; platform could not be determined
  • 307 — redirect (temporary)
  • none / error — site was unreachable or returned an error

Only sites returning 200 could have their platform identified.

techstack-opensource-platform

Whether the detected platform is open source. Values:

  • yes — confirmed open-source platform (e.g., WordPress, Joomla, Drupal)
  • no — confirmed proprietary platform (e.g., ASP.NET, Sitecore, Granicus)
  • unknown — site was reachable but platform could not be identified
  • error — site was unreachable during scanning
  • blank — not scanned

techstack-platform

The specific CMS or web platform detected. Examples include WordPress, ASP.NET (proprietary/custom), Joomla, Sitecore, Drupal, and Granicus/GovDelivery. Sites that returned a non-200 status or where detection was inconclusive are marked undetermined.

techstack-frameworks

Third-party JavaScript libraries and tools detected on the page (e.g., jQuery, Bootstrap, Google Analytics, Google Tag Manager, YouTube Embed). Multiple values are separated by semicolons. Blank where none were detected or the site was not scanned.

Notes

  • Hostnames include staging, test, and internal environments in addition to public production sites; traffic figures help distinguish between them.
  • Only the top 155 hostnames by traffic were scanned; findings should not be generalized to all 1,115 hostnames in the dataset.
  • Findings should be interpreted at the hostname level, not the agency level — a single agency may operate multiple hostnames on different platforms.
