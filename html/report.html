Overview

Audit of 155 top California government websites. I used data from Google Analytics to help determine which hostnames to scan. I used a crawler and source code to determine the kind of technology.

Key findings

83 of the scanned sites had an identifiable platform. 56 of those are on open-source platforms (67%) and 27 run proprietary platforms (33%).

Method

I created the hostname list from a Google Analytics report of sites using the statewide CA.gov tag over a 28-day window (July 1–28, 2026). The original list had 1,227 hostname records. The dataset was then deduplicated and numeric-only entries were removed leaving 1,115 hostnames. The numeric-only entries were likely IP addresses rather than named web properties.

The scanner ran on the top 155 sites by traffic volume. A Python script crawled each site and inspected HTTP response headers and HTML source. Then it identified the underlying platform and classified it as open source or proprietary. Only sites returning HTTP 200 could be fingerprinted. The script marked blocked (403), redirecting, or unreachable sites accordingly. The remaining 959 hostnames were not scanned and have no platform classification.

Limitations of this report

  • This dataset does not include sites that do not use the statewide Google Analytics tag.
  • Only the top 155 hostnames by traffic were scanned.
  • The scanner could not analyze sites that block automated traffic.
  • The Google Analytics list of 1227 hostnames includes some staging, test, and internal environments.
  • The audit reports at the hostname level, not the agency level. A single agency may operate multiple hostnames on different platforms.
